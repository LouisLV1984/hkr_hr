# leave (L3)

Annual leave balances/allocations/records, comp leave credits/allocations, work injury periods and medical expense claims, absence integrity rules and leave review.

Owned tables: `employee_annual_leave_balances`, `employee_annual_leave_allocations`, `employee_annual_leave_records`, `employee_comp_leave_credits`, `employee_comp_leave_allocations`, `employee_work_injury_periods`, `employee_work_injury_monthly_expenses`.
