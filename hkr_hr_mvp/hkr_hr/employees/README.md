# employees (L2)

Employee master records, employment periods, assignments, identities, visas, certificates, qualifications, bank accounts, salaries, allowances, MPF enrollments, completeness checks, profile integrity and revision locking.

Owned tables: `employees`, `employee_employment_periods`, `employee_assignments`, `employee_identities`, `employee_visas`, `employee_certificates`, `employee_qualifications`, `employee_bank_accounts`, `employee_salaries`, `employee_allowances`, `employee_mpf_enrollments`, `employee_attendance_policies`, `employee_task_notes`.
